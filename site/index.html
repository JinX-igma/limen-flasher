Limen

在 Chrome 或 Edge 中通过 USB 将 Limen Gateway 客户端烧录到 ESP32、ESP32-S3 或 ESP32-C3。设备从不保存真实 OpenAI API key。

  1. 连接开发板并点击“连接并烧录”。
  2. 首次启动后连接设备创建的 Limen-Codex-XXXXXX Wi-Fi，密码为 limen-codex。
  3. 打开 http://192.168.4.1，填写 Wi-Fi、网关地址与设备令牌（由网关运营者签发，而非 OpenAI API key）。
  4. 回到 115200 波特率串口，输入一行提示词开始使用。
当前浏览器不支持 Web Serial，请使用桌面版 Chrome 或 Edge。

设备只保存网关签发的可撤销令牌，而不是真实 OpenAI API key；该令牌可在不影响其他设备的情况下随时撤销。
