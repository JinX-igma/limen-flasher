Limen ESP32 Codex

在 Chrome 或 Edge 中通过 USB 将 OpenAI Responses API 客户端烧录到 ESP32、ESP32-S3 或 ESP32-C3。

  1. 连接开发板并点击“连接并烧录”。
  2. 首次启动后连接设备创建的 Limen-Codex-XXXXXX Wi-Fi，密码为 limen-codex。
  3. 打开 http://192.168.4.1，填写 Wi-Fi 与 OpenAI API key。
  4. 回到 115200 波特率串口，输入一行提示词开始使用。
当前浏览器不支持 Web Serial，请使用桌面版 Chrome 或 Edge。

API key 会保存在设备 NVS 中。请使用独立项目 key 和低额度限制；任何可能落入他人手中的设备都应改用后端代理。
